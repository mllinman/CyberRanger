CyberRanger - Wi-Fi & Bluetooth Scanner
====================================================

Features:
- Dark mode modern UI
- Tabbed interface: Wi-Fi & Bluetooth
- Real-time scanning
- White-hat/Pentester use only

Build Instructions:
1. Install Qt 6 and CMake.
2. Open Qt command prompt.
3. cd to project folder:
   mkdir build
   cd build
   cmake ..
   cmake --build . --config Release
4. Run CyberRanger.exe

Resources:
- /resources/darktheme.qss
- /resources/icons/ (wifi.png, bluetooth.png)
