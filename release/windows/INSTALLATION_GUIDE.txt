# CyberRanger Windows Installation Guide

## Package Contents:

This installer package contains:
- `CyberRanger.exe` - Main application executable
- `assets/` - Application icons and images
- `resources/` - UI stylesheets and themes  
- `modules/` - Scanner modules and plugins
- `config/` - Configuration files
- `run_cyberranger.bat` - Launcher script
- Documentation files

## Installation Instructions:

### Method 1: Using the Installer (Recommended)
1. Download `CyberRanger_Setup_v1.0.0.exe`
2. Right-click and select "Run as Administrator"
3. Follow the installation wizard
4. Launch from Start Menu or Desktop shortcut

### Method 2: Portable Installation
1. Extract the contents of this package to a folder (e.g., `C:\CyberRanger`)
2. Ensure all files are in the same directory
3. Double-click `run_cyberranger.bat` to start the application

## System Requirements:

- **Operating System**: Windows 10 or later (64-bit)
- **Memory**: 4 GB RAM minimum, 8 GB recommended
- **Disk Space**: 100 MB for application, 500 MB for logs and data
- **Network**: Administrative privileges may be required for some scans
- **Dependencies**: 
  - Visual C++ Redistributable 2019 or later
  - Qt6 Runtime Libraries (included with installer)

## Prerequisites:

### Visual C++ Redistributable
If the application fails to start, download and install:
- Microsoft Visual C++ 2019-2022 Redistributable (x64)
- Available from: https://aka.ms/vs/17/release/vc_redist.x64.exe

### Windows Defender / Antivirus
Network scanning tools are often flagged by antivirus software:
1. Add CyberRanger directory to your antivirus exclusions
2. Or temporarily disable real-time protection during installation
3. This is normal for legitimate security tools

## First Run:

1. **Legal Disclaimer**: You'll be prompted to accept the legal disclaimer
2. **Administrative Rights**: Run as Administrator for full functionality
3. **Network Permissions**: Allow through Windows Firewall if prompted
4. **Dashboard**: Start with the Dashboard tab for an overview

## Features:

- **Wi-Fi Scanner**: Discover wireless networks in range
- **Bluetooth Scanner**: Find nearby Bluetooth devices
- **Network Scanner**: Map network topology and open ports
- **Dark Theme Interface**: Modern, professional UI
- **Legal Compliance**: Built-in disclaimer and ethical use guidelines

## Troubleshooting:

### Application Won't Start
- Ensure Visual C++ Redistributable is installed
- Check Windows Event Log for specific error messages
- Try running as Administrator
- Verify all files are present in installation directory

### Scanner Issues
- Requires Administrative privileges for low-level network access
- Some functionality may need Windows Firewall exceptions
- Antivirus may block scanning activities (whitelist as needed)

### Performance Issues  
- Close unnecessary applications
- Ensure adequate RAM (8GB+ recommended)
- Check for Windows Updates
